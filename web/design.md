# Design — TripRanker

A locked design system for this app. Every page redesign reads this file before
emitting code. Do not regenerate per page — extend or amend this file when the
system needs to grow.

## Genre

playful (post-Linear soft school, commerce-flavoured) — friendly ID copy,
soft radius, deal-energy accents. Informational pages (MLOps/Data) borrow the
same voice but stay dense and factual.

## Macrostructure family

- App pages (shop `/`): **Commerce Storefront** — hero + search · horizontal
  bestseller rail (scroll-snap) · live recommendation grid · session trail.
  Variation knob: rail content (bestseller / karena-kamu-klik).
- Content pages (`/mlops`, `/data`): **Ledger** — verdict first (scoreboard /
  key numbers), then evidence rows, then method. MLOps varies with Duel
  archetype (head-to-head bars); Data varies with Timeline archetype
  (numbered steps + copyable commands).

## Theme

Locked to TripRanker brand (`web/app/brand.theme.css`, generated from
`docs/pocket/rule/creative-brief.md`). No per-page theme picks.

- `--color-paper` n100 page · cards white · `--color-ink` n900
- `--color-accent` Cart Ember a500 — deal badges + cart CTA only (≤5% per viewport)
- `--color-focus` p700 · radius `--radius-brand: 10px` · pill 99px for badges
- Signal Blue p700 header band on shop hero only; MLOps/Data stay paper.

## Typography

- Display: Space Grotesk 500/700, normal style (never italic headers)
- Body: Inter 400/500/600 · Mono: system mono for numbers/commands
- Scale (base 16, ratio 1.20): xs 11 · sm 13 · base 16 · md 19 · lg 23 · xl 28
- Hero headline ≤7 words where we write it; wraps via overflow-wrap:anywhere

## Spacing

4pt scale via Tailwind utilities; section rhythm: hero tight → rail airy →
grid dense. `max-w-lg` mobile column; rails bleed full-width inside it.

## Motion

- Easings: ease-out default; transform + opacity only
- Primitives (≤3): optimistic-tap (card presses in 120ms) · shimmer-skeleton
  (loading) · scroll-snap rails. No scroll reveals.
- Reduced-motion: opacity crossfade ≤150ms.

## Microinteractions stance

- silent success: tap → card updates + toast-less inline confirm
  ("Masuk keranjang ✓" inline, not a dialog)
- optimistic update + no undo needed (events are append-only session trail)
- search: submit-driven ("Lihat rekomendasi"), no debounce-fetch
- hover delay n/a (touch-first); focus delay 0ms, visible p700 ring

## CTA voice

- Primary CTA: accent fill a500, radius-brand, copy pattern verb+object
  ("+ Keranjang", "Lihat rekomendasi")
- Secondary: p100 fill + p700 text ("Nanti dulu" pattern where needed)
- Explainability: "Kenapa ini?" ghost link per reco card (expandable reason)

## Per-page allowances

- Shop MAY use deal badges (Terlaris / −x% / Laris) derived from real rank/conv.
- App pages MUST NOT use photographic enrichment — CSS gradient thumbs only.
- Content pages: typography + bars only, no thumbs.

## What pages MUST share

- Wordmark "TripRanker" + Signal Blue anchor.
- Cart Ember accent placement (badges + cart buttons only).
- Space Grotesk display + Inter body.
- CTA voice above; tab bar (Belanja · MLOps · Data) with position indicator.
- Honest numbers only: views/carts/ranks from Postgres + popularity.csv.
  Product names/prices are clearly-labelled illustrative catalogue dressing
  for anonymous RetailRocket item ids (names derived deterministically from
  item_id, prices deterministic IDR) — never presented as dataset fields.

## What pages MAY differ on

- Macrostructure within family (Storefront vs Ledger-Duel vs Ledger-Timeline).
- Rail vs grid vs timeline section order to fit the page job.

## Exports

Tokens live in `web/app/brand.theme.css` (Tailwind v4 `@theme`, generated by
/brand-design from the creative brief). Single source — no duplicate export.
